# JY-2026-06

JY2026年6月份临时需求工具。

## 桌面工具箱

启动方式：

```bash
pip install -r requirements.txt
python toolbox_app.py
```

### 已包含功能

- 主界面采用更清爽的顶部操作区和卡片式内容区，不再把工具列表固定占在左侧。
- 点击顶部“工具列表”会以弹窗形式打开分类工具列表；每个分类是独立卡片，支持新增分类、删除分类、分类改名。
- 工具按钮可在工具列表弹窗内拖动到任意分类卡片中，释放后会自动归属到该分类。
- 顶部提供全局“密码本”按钮，可新增多个 Excel 打开密码、勾选删除密码；列表中会隐藏密码中间字符。
- 每个工具页面顶部只展示一两行“说明”，旁边提供小“编辑”按钮，可随时修改或恢复默认说明。
- 每个工具的输入内容、输出路径、工具说明等状态独立保存到 `~/.jy_toolbox/config.json`，下次打开会自动填充。

### 贴文去重

“贴文去重”工具会读取 Excel，并根据 `贴文url` 列去重。重复 URL 中会先比较 `点赞数`、`分享数`、`评论数` 三列的数值总和，保留总和更大的记录；如果总和相同，则随机保留一条。

如果 Excel 文档有打开密码，工具会按密码本中的密码顺序逐个尝试打开。

### 数据前提存档

后续新增功能默认围绕两类本地 Excel：账号表和贴文表。账号表只依赖 `FB主页` 列；贴文表通过 `主页url` 列与账号表关联，常见列包括 `贴文url`、`用户名`、`主页url`、`标题`、`帖子正文`、`贴文发布时间`、`发布地址`、`图片附件`、`点赞数`、`分享数`、`评论数`、`创作类型` 等。`创作类型` 中 `common` 表示原创贴文，`share` 表示转发贴文；`图片附件` 中如果只有一个附件通常视为头像，如果包含多个附件通常表示头像和贴文图片。

全局执行要求：耗时功能均应放到后台线程执行，并在界面展示进度条，避免处理大 Excel 时界面卡住。

### 贴文类型占比（%）

“贴文类型占比（%）”工具会选择账号 Excel 和贴文 Excel，通过账号表 `FB主页` 与贴文表 `主页url` 关联，统计每个账号文字、图片、视频三类贴文占比，并在账号表最后新增 `帖子类型` 列输出。

判断规则：

- `图片附件` 中能找到 2 个或以上 `origin_url_md5` 的，归为图片。
- `主页url` 或 `贴文url` 中包含 `/videos/` 的，归为视频。
- 剩余贴文中，必须 `创作类型` 为 `common`，且 `标题` 或 `帖子正文` 任一列不为空，才归为文字。
- 无法判断的贴文暂不参与文字、图片、视频占比统计。
