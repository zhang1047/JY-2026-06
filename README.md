# JY-2026-06

JY2026年6月份临时需求工具。

## 桌面工具箱

启动方式：

```bash
pip install -r requirements.txt
python main.py
# 仍支持包方式启动：python -m jy_toolbox
```


## 代码结构

项目已拆分为标准 Python 包，避免把界面、业务逻辑和配置全部堆在单个文件中：

```text
main.py                    # 应用启动入口
jy_toolbox/
├── core/                   # 常量、配置、本地平台适配、通用模型
├── services/               # Excel 读取、统计、去重等纯业务函数
└── ui/                     # Tkinter 主界面、弹窗、控件和各工具页面
```

根目录 `main.py` 是唯一的应用启动入口；`python -m jy_toolbox` 仅通过包入口转发到它。

### 已包含功能

- 主界面采用更清爽的顶部操作区和卡片式内容区，不再把工具列表固定占在左侧。
- 点击顶部“工具列表”会以弹窗形式打开分类工具列表；每个分类是独立卡片，支持新增分类、删除分类、分类改名。
- 工具按钮可在工具列表弹窗内拖动到任意分类卡片中，释放后会自动归属到该分类。
- 顶部提供全局“密码本”按钮，可新增多个 Excel 打开密码、勾选删除密码；列表中会隐藏密码中间字符。
- 每个工具页面顶部只展示一两行“说明”，旁边提供小“编辑”按钮，可随时修改或恢复默认说明。
- 每个工具的输入内容、输出路径、工具说明等状态独立保存到 `~/.jy_toolbox/config.json`，下次打开会自动填充。

### 贴文去重

“贴文去重”工具会读取 Excel，并根据 `贴文url` 列去重。重复 URL 中会先比较 `点赞数`、`分享数`、`评论数` 三列的数值总和，保留总和更大的记录；如果总和相同，则随机保留一条。

如果 Excel 文档有打开密码，工具会按密码本中的密码顺序逐个尝试打开。

### 数据前提存档

后续新增功能默认围绕两类本地 Excel：账号表和贴文表。账号表只依赖 `FB主页` 列；贴文表通过 `主页url` 列与账号表关联，常见列包括 `贴文url`、`用户名`、`主页url`、`标题`、`帖子正文`、`贴文发布时间`、`发布地址`、`图片附件`、`点赞数`、`分享数`、`评论数`、`创作类型` 等。`创作类型` 中 `common` 表示原创贴文，`share` 表示转发贴文；`图片附件` 中如果只有一个附件通常视为头像，如果包含多个附件通常表示头像和贴文图片。

全局执行要求：耗时功能均应放到后台线程执行，并在界面展示进度条，避免处理大 Excel 时界面卡住。

### 贴文类型占比（%）

“贴文类型占比（%）”工具会选择账号 Excel 和贴文 Excel，通过账号表 `FB主页` 与贴文表 `主页url` 关联，统计每个账号文字、图片、视频三类贴文占比，并在账号表最后新增 `文字帖占比`、`图片帖占比`、`视频帖占比` 三列输出百分比数值。

判断规则：

- `主页url` 或 `贴文url` 中包含 `/videos/` 的，优先归为视频。
- 不是视频时，`图片附件` 中能找到 2 个或以上 `origin_url_md5` 的，归为图片。
- 剩余贴文中，必须 `创作类型` 为 `common`，且 `标题` 或 `帖子正文` 任一列不为空，才归为文字。
- 无法判断的贴文暂不参与文字、图片、视频占比统计。


### 高频发帖时段类型

“高频发帖时段类型”工具会选择账号 Excel、贴文 Excel 和发帖时段字典 Excel，通过账号表 `FB主页` 与贴文表 `主页url` 关联，读取贴文表 `贴文发布时间`，按字典表中的时段定义判断每条贴文所属时段，再按账号统计最高频的发帖时段类型。

字典表需要包含以下列：

- `时段类型`
- `起始时段`
- `结束时段`

工具不会固定写死时段数量；会以字典表中有有效 `起始时段` 和 `结束时段` 的行作为实际时段定义。比如字典从 4 类改为 3 类时，会自动按 3 类统计。支持跨天时段，例如 `23:00:00` 到 `4:59:59`。

处理完成后，工具会在账号表最后新增 `高频发帖时段`、`高频发帖类型` 两列。`高频发帖时段` 写入对应字典时段，例如 `5:00:00~7:59:59`；`高频发帖类型` 写入对应 `时段类型`，例如 `晨间型`。如果账号在所有字典时段都有发帖，且各时段占比之间的最大差值不高于 10%，则判为混乱型，只写入 `高频发帖类型`，`高频发帖时段` 留空。若字典中存在无有效起止时段的类型行，会使用该行 `时段类型` 作为混乱型名称；否则默认写入 `混乱型`。

### 活跃天数占比（%）

“活跃天数占比（%）”工具会选择账号 Excel 和贴文 Excel，通过账号表 `FB主页` 与贴文表 `主页url` 关联，读取贴文表 `贴文发布时间` 列（例如 `2025-10-14 11:57:01`），按账号计算：

活跃天数占比 = 该账号实际有贴文的日期数量 / 该账号最早贴文日期到最晚贴文日期的总天数 × 100%

处理完成后，工具会在账号表最后依次新增 `帖子数量`、`帖子时间跨度天数`、`活跃天数`、`活跃天数占比` 四列。`帖子数量` 写回每个账号匹配到的贴文数量；`帖子时间跨度天数` 写回从最早发帖日期到最晚发帖日期的总天数；`活跃天数` 写回实际有贴文的日期数量；`活跃天数占比` 格式例如 `40.00%`。同一天多条贴文只计为 1 个活跃日期；同一账号最早和最晚贴文在同一天时，时间范围按 1 天计算。

注意：`帖子数量` 统计所有可匹配账号的贴文；`活跃天数占比` 只要贴文表中存在一条可匹配账号且 `贴文发布时间` 可解析的贴文数据，就会计入统计；即使帖子正文为空也计入，转发贴也计入。

### 平均发帖长度

“平均发帖长度”工具会选择账号 Excel 和贴文 Excel，通过账号表 `FB主页` 与贴文表 `主页url` 关联，计算每个账号的平均每个帖子的正文长度。

统计规则：

- 只统计贴文表 `帖子正文` 列的文字长度，不使用标题或其他字段。
- 每条贴文都会参与该账号平均值计算；`帖子正文` 为空时该条贴文长度按 `0` 计算。
- 处理完成后，工具会在账号表最后新增 `平均发帖长度` 一列；如果账号没有可匹配贴文，则该列留空。

界面支持分别填写账号表和贴文表的工作表名；工作表名留空时读取第一个工作表。

### 信息来源的媒体阵营分布（%）

“信息来源的媒体阵营分布（%）”工具会选择账号 Excel、贴文 Excel 和账号名字典 Excel，仅统计贴文表中 `创作类型` 为 `share` 的转发贴。工具通过账号表 `FB主页` 与贴文表 `主页url` 关联；再用贴文表 `分享贴账号名` 到字典表中匹配同名账号，读取字典表的 `账号立场归属` 和 `账号类型归属`。

处理完成后，工具会在账号表最后新增 `账号立场归属占比`、`账号类型归属占比`、`官方信源占比` 三列；前两列内容格式类似 `abc：20.00%；bcd：30.00%；qwe：50.00%`，`官方信源占比` 仅统计 `账号类型归属` 为 `政府/军警机关` 的分享贴账号在全部可判断类型分享贴账号中的占比，格式类似 `20.00%`。如果账号没有可匹配的分享贴账号名或没有可判断类型的分享贴账号，对应占比列留空。

字典表需要包含以下列：

- `分享贴账号名`
- `账号立场归属`
- `账号类型归属`

界面支持分别填写账号表、贴文表和字典表的工作表名；工作表名留空时读取第一个工作表。

### 附加观点转发率（%）

“附加观点转发率（%）”工具会选择账号 Excel 和贴文 Excel，通过账号表 `FB主页` 与贴文表 `主页url` 关联，仅统计贴文表中 `创作类型` 为 `share` 的转发贴。

判断规则：转发贴中只要 `标题` 或 `帖子正文` 任意一个不为空，就视为带有附加观点。工具会按账号计算：

```text
附加观点转发率 = 带有附加观点的转发贴数量 / 该账号全部转发贴数量 × 100%
```

处理完成后，工具会在账号表最后新增 `附加观点转发率` 一列，格式例如 `25.00%`。如果某个账号没有可统计的转发贴，则该列留空。
