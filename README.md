# JY-2026-06

JY 2026 年 6 月份临时需求工具。当前项目是一个基于 Python + Tkinter 的桌面 Excel 数据处理工具箱，主要围绕“账号表”和“帖子表”做批量统计、清洗和指标回写。

## 启动方式

```bash
pip install -r requirements.txt
python main.py
# 仍支持包方式启动
python -m jy_toolbox
```

## 数据前提

后续新增功能默认围绕两类本地 Excel：账号表和帖子表。

- **账号表**：通常至少需要 `FB主页` 列，用于与帖子表关联。
- **帖子表**：通常通过 `主页url` 列与账号表关联，常见列包括 `帖子url`、`用户名`、`主页url`、`标题`、`帖子正文`、`帖子发布时间`、`发布地址`、`图片附件`、`点赞数`、`分享数`、`评论数`、`创作类型`、`分享帖账号名` 等。
- **创作类型**：`common` 通常表示原创帖子，`share` 通常表示转发帖子。
- **图片附件**：如果只有一个附件通常视为头像；如果包含多个附件，通常表示头像和帖子图片。

## 全局功能

- **图形化桌面工具箱**：提供卡片式工具页面、顶部操作区和统一状态提示。
- **工具列表与分组管理**：点击顶部“工具列表”可打开分组弹窗；支持新增分组、删除分组、分组改名，并可拖动工具按钮到任意分组卡片中。
- **分组一键执行**：进入某个分组后，可选择账号表、帖子表、必要的字典表和工作表，一次性按分组内工具顺序串行执行。中间结果写入临时文件，最后一个工具输出最终账号表。
- **Excel 密码本**：顶部“密码本”可维护多个 Excel 打开密码；读取加密 Excel 时会依次尝试密码，列表中会隐藏密码中间字符。
- **工作表选择**：各工具支持选择账号表、帖子表、字典表的工作表名；不填写时默认读取第一个工作表。
- **工具说明可编辑**：每个工具页面顶部展示说明，并提供“编辑”按钮，可修改或恢复默认说明。
- **状态持久化**：每个工具的输入路径、输出路径、工作表名、工具说明、自定义关键词等配置会保存到 `~/.jy_toolbox/config.json`，下次打开自动填充。
- **后台执行与进度提示**：耗时功能放到后台线程执行，并在界面展示进度，避免大 Excel 处理时界面卡住。
- **输出列覆盖策略**：多数统计工具写出前会先删除同名旧输出列，再在账号表末尾追加最新计算结果。

## 全部工具功能

### 1. 帖子去重

选择一个帖子 Excel，按 `帖子url` 去重并输出新文件。

- 必要列：`帖子url`、`点赞数`、`分享数`、`评论数`。
- 对同一 `帖子url` 的重复行，计算 `点赞数 + 分享数 + 评论数` 作为互动得分。
- 保留互动得分最高的一行；如果得分相同，会随机保留一行。
- 最终输出保留原始行顺序。

### 2. 帖子类型占比（%）

选择账号 Excel 和帖子 Excel，通过账号表 `FB主页` 与帖子表 `主页url` 关联，统计每个账号文字、图片、视频三类帖子占比。

- 输出列：`文字帖子占比`、`图片帖子占比`、`视频帖子占比`。
- 视频判断：`主页url` 或 `帖子url` 包含 `/videos/` 时，优先归为视频。
- 图片判断：非视频且 `图片附件` 中出现 2 个或以上 `origin_url_md5` 时，归为图片。
- 文字判断：非视频、非图片，且 `创作类型` 为 `common`，并且 `标题` 或 `帖子正文` 任一不为空时，归为文字。
- 无法判断的帖子不参与三类占比计算。

### 3. 高频发帖时段类型

选择账号 Excel、帖子 Excel 和发帖时段字典 Excel，按字典定义判断每条帖子发布时间所属时段，再按账号统计最高频时段类型。

- 字典必要列：`时段类型`、`起始时段`、`结束时段`。
- 输出列：`高频发帖时段`、`高频发帖类型`。
- 支持任意数量时段定义，不写死为固定 3 类或 4 类。
- 支持跨天时段，例如 `23:00:00` 到 `4:59:59`。
- 如果某账号在所有字典时段都有发帖，且各时段占比最大差值不高于 10%，判为混乱型：只写 `高频发帖类型`，`高频发帖时段` 留空。
- 如果字典中有无有效起止时段但填写了 `时段类型` 的行，该类型名会作为混乱型名称；否则默认写入 `混乱型`。

### 4. 帖子主题占比（%）

选择账号 Excel、帖子 Excel 和内容偏好字典 Excel，通过帖子正文匹配字典中的主题/内容偏好分组，按账号统计各主题占比。

- 字典第一列必须为 `帖子正文`。
- 字典需包含 `内容偏好` 列。
- 用帖子表 `帖子正文` 与字典第一列 `帖子正文` 精确匹配。
- 按账号汇总各 `内容偏好` 分组的数量占比。
- 输出列按主题动态生成，格式为 `主题占比-分组名`。

### 5. 敏感话题参与率（%）

选择账号 Excel、帖子 Excel 和敏感话题关键词字典 Excel，统计每个账号参与敏感话题的帖子占比。

- 字典按无表头读取，第一列为关键词列表。
- 扫描帖子 `标题` 和 `帖子正文`。
- 只要帖子标题或正文包含任一关键词，即视为敏感话题帖子。
- 计算公式：`敏感话题参与率 = 命中关键词的帖子数 / 该账号全部帖子数 × 100%`。
- 输出列：`敏感话题参与率（%）`。
- 内部使用快速多关键词匹配索引，适合较多关键词场景。

### 6. 自定义关键词统计

选择账号 Excel 和帖子 Excel，在界面中维护多个自定义关键词，统计每个账号所有帖子标题和正文中的关键词出现次数。

- 支持新增、删除关键词。
- 支持关键词“一键转繁体”和“一键转简体”。
- 支持“不区分简繁体”，开启后会同时统计原词、简体和繁体变体。
- 统计范围：同账号所有帖子的 `标题` 和 `帖子正文`。
- 输出列按关键词动态生成，格式为 `词频-关键词`。
- 统计方式为字符串出现次数累加；没有命中的账号写入 0。

### 7. 情感表达分数&数量占比

选择账号 Excel、帖子 Excel 和情感表达字典 Excel，通过帖子正文匹配情感倾向，按账号汇总情感分数、数量和占比。

- 字典第一列必须为 `帖子正文`。
- 字典必要列：`情感表达倾向`。
- 支持枚举：`正面`、`负面`、`中性`。
- 分值规则：正面 `+1`，负面 `-1`，中性 `0`。
- 输出列：`情感表达-分数`、`情感表达-正面（数量）`、`情感表达-正面（占比）`、`情感表达-负面（数量）`、`情感表达-负面（占比）`、`情感表达-中性（数量）`、`情感表达-中性（占比）`。

### 8. 立场倾向分数&数量占比

选择账号 Excel、帖子 Excel 和立场倾向字典 Excel，通过帖子正文匹配两岸议题立场，按账号汇总立场分数、数量和占比。

- 字典第一列必须为 `帖子正文`。
- 字典必要列：`两岸议题立场倾向`。
- 支持枚举：`偏蓝`、`中立`、`偏绿`。
- 分值规则：偏蓝 `+1`，中立 `0`，偏绿 `-1`。
- 输出列：`立场倾向-分数`、`立场倾向-偏蓝（数量）`、`立场倾向-偏蓝（占比）`、`立场倾向-偏绿（数量）`、`立场倾向-偏绿（占比）`、`立场倾向-中立（数量）`、`立场倾向-中立（占比）`。

### 9. 日均在线活跃时段跨度（小时/天）

选择账号 Excel 和帖子 Excel，按账号计算日均在线活跃时段跨度。

- 必要列：账号表 `FB主页`；帖子表 `主页url`、`帖子发布时间`。
- 仅统计每个账号单日发帖 2 条及以上的日期。
- 对每个有效日期，计算当天最早发帖时间到最晚发帖时间的间隔小时数。
- 再对该账号所有有效日期的间隔取平均。
- 输出列：`日均在线活跃时段跨度（小时/天）`。

### 10. 活跃天数占比（%）

选择账号 Excel 和帖子 Excel，通过帖子发布时间计算账号活跃天数占比。

- 输出列：`帖子数量`、`帖子时间跨度天数`、`活跃天数`、`活跃天数占比`。
- 计算公式：`活跃天数占比 = 实际有帖子的日期数量 / 最早帖日期到最晚帖日期的总天数 × 100%`。
- 同一天多条帖子只计为 1 个活跃日期。
- 同一账号最早和最晚帖子在同一天时，时间跨度按 1 天计算。
- 只要帖子表存在可匹配账号且 `帖子发布时间` 可解析的帖子，就计入统计；正文为空或转发帖也计入。

### 11. 平均发帖长度

选择账号 Excel 和帖子 Excel，计算每个账号平均每条帖子的正文长度。

- 必要列：账号表 `FB主页`；帖子表 `主页url`、`帖子正文`。
- 只统计 `帖子正文` 的文字长度，不使用标题或其他字段。
- 每条帖子都会参与平均值计算；`帖子正文` 为空时长度按 0 计算。
- 输出列：`平均发帖长度`。
- 账号没有可匹配帖子时，输出留空。

### 12. 日均原创量（条）

选择账号 Excel 和帖子 Excel，计算每个账号在统计时间范围内的日均原创发帖量。

- 必要列：账号表 `FB主页`；帖子表 `主页url`、`创作类型`、`帖子发布时间`。
- 先按每个账号最早到最晚的帖子发布时间计算统计天数，最少按 1 天计算。
- 排除 `创作类型` 为 `share` 的转发帖子，其余帖子视为原创统计。
- 计算公式：`日均原创量 = 原创帖子数量 / 统计时间范围天数`。
- 输出列：`日均原创量（条）`。

### 13. 每周发布帖子频率（次）

选择账号 Excel 和帖子 Excel，计算每个账号平均每周发布帖子频率。

- 必要列：账号表 `FB主页`；帖子表 `主页url`、`帖子发布时间`。
- 按每个账号最早到最晚的帖发布日期计算统计自然周数。
- 统计周数包含首尾日期，向上取整且最少为 1 周。
- 输出列：`跨越周数`、`每周发布帖子频率（次）`。

### 14. 平均原创单帖子互动数（条）

选择账号 Excel 和帖子 Excel，计算原创帖的平均单帖互动数。

- 必要列：账号表 `FB主页`；帖子表 `主页url`、`创作类型`、`点赞数`、`分享数`、`评论数`。
- 仅统计 `创作类型` 为 `common` 的原创帖子。
- 每帖互动数 = `点赞数 + 评论数 + 分享数`。
- 按账号计算原创帖互动数平均值。
- 输出列：`平均原创单帖子互动数（条）`。

### 15. 附加观点转发率（%）

选择账号 Excel 和帖子 Excel，仅统计转发帖子中带有附加观点的比例。

- 必要列：账号表 `FB主页`；帖子表 `主页url`、`创作类型`、`标题`、`帖子正文`。
- 仅统计 `创作类型` 为 `share` 的转发帖子。
- 转发帖子中只要 `标题` 或 `帖子正文` 任意一个不为空，即视为带有附加观点。
- 计算公式：`附加观点转发率 = 带有附加观点的转发帖子数量 / 该账号全部转发帖子数量 × 100%`。
- 输出列：`附加观点转发率`。
- 账号没有可统计的转发帖子时，输出留空。

### 16. 信息来源的媒体阵营分布（%）

选择账号 Excel、帖子 Excel 和账号名字典 Excel，仅统计转发帖的信息来源分布。

- 仅统计帖子表中 `创作类型` 为 `share` 的转发帖子。
- 通过账号表 `FB主页` 与帖子表 `主页url` 关联。
- 再用帖子表 `分享帖账号名` 到字典表中匹配同名账号。
- 字典必要列：`分享帖账号名`、`账号立场归属`、`账号类型归属`。
- 输出列：`账号立场归属占比`、`账号类型归属占比`、`官方信源占比`。
- `账号立场归属占比` 和 `账号类型归属占比` 的格式类似：`abc：20.00%；bcd：30.00%；qwe：50.00%`。
- `官方信源占比` 仅统计 `账号类型归属` 为 `政府/军警机关` 的分享帖账号，在全部可判断类型分享帖账号中的占比。
- 账号没有可匹配分享帖账号名或没有可判断类型时，对应列留空。

## 代码结构

项目已拆分为标准 Python 包，避免把界面、业务逻辑和配置全部堆在单个文件中：

```text
main.py                    # 应用启动入口
jy_toolbox/
├── core/                   # 常量、配置、本地平台适配、简繁转换、通用模型
├── services/               # Excel 读取、去重、统计分析等纯业务函数
└── ui/                     # Tkinter 主界面、弹窗、控件和各工具页面
```

根目录 `main.py` 是唯一的应用启动入口；`python -m jy_toolbox` 仅通过包入口转发到它。

## 使用的技术

- **Python 3**：项目主语言。
- **Tkinter / ttk**：构建桌面 GUI、弹窗、表单、按钮、进度条和工具页面。
- **pandas**：读取、清洗、分组统计和写出 Excel 数据。
- **openpyxl**：作为 `.xlsx` 读写引擎。
- **msoffcrypto-tool**：尝试使用密码本中的密码解密受保护的 Excel 文件。
- **threading / queue**：耗时处理在后台线程执行，主线程通过队列刷新进度和结果。
- **pathlib / tempfile / shutil**：处理文件路径、一键执行中间临时文件和临时目录清理。
- **JSON 配置持久化**：将工具状态、分组、说明、密码等保存在用户目录 `~/.jy_toolbox/config.json`。
- **Aho-Corasick 风格多关键词匹配**：敏感话题参与率工具内部构建快速关键词匹配索引，用于批量扫描标题和正文。
- **内置简繁转换映射**：自定义关键词工具支持关键词简体/繁体转换及不区分简繁体统计。
