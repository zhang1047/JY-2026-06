# JY-2026-06

JY2026年6月份临时需求工具。

## 桌面工具箱

启动方式：

```bash
pip install -r requirements.txt
python toolbox_app.py
```

### 已包含功能

- 左侧工具列表按分类显示，每个分类是独立框体；支持新增分类、删除分类、分类改名。
- 工具按钮可拖动到任意分类框体中，释放后会自动归属到该分类。
- 右上角提供全局“密码本”按钮，可新增多个 Excel 打开密码、勾选删除密码；列表中会隐藏密码中间字符。
- 每个工具的输入内容、输出路径等状态独立保存到 `~/.jy_toolbox/config.json`，下次打开会自动填充。

### 贴文去重

“贴文去重”工具会读取 Excel，并根据 `贴文url` 列去重。重复 URL 中会先比较 `点赞数`、`分享数`、`评论数` 三列的数值总和，保留总和更大的记录；如果总和相同，则随机保留一条。

如果 Excel 文档有打开密码，工具会按密码本中的密码顺序逐个尝试打开。
